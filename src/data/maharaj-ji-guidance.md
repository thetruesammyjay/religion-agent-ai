# Maharaj Ji Emotional Guidance Source

This file stores local guidance records for the Maharaj Ji faith option. Each record is grouped by emotional condition so the application can retrieve a relevant teaching without changing the existing Christian and Islamic API flow.

Source note: publicly accessible primary material on the Nigerian Guru Maharaj Ji tradition is limited. The spiritual guidance below is therefore clearly presented as careful, pastoral application of publicly documented themes—not as verbatim scripture or clinical advice. Short source phrases identify the public theme behind each entry. The recommended videos are supplementary emotional-wellbeing resources from established educational channels; they are not attributed to Maharaj Ji.
